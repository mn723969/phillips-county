# Phillips County, Arkansas: Community Data Dashboard

Live site: https://mn723969.github.io/phillips-county/

A community data dashboard for Phillips County, Arkansas, prepared by the Arkansas Health Equity and Access Lab (HEAL) at the University of Arkansas in partnership with the Arkansas Foodbank. It brings together social determinants of health, physical health and behavioral health data by neighborhood, plus a map of community resources.

The entire dashboard is the single self-contained file `index.html`. Sources and notes are listed in the dashboard's "About the data" tab.

*Beta version.*
